# Scene generator

The scene HTML in `compositions/` was generated by these scripts (palms, stones, figures, hands and tools are built procedurally).
`python3 s1.py` … `python3 s5.py` rewrite the matching scene; `python3 index.py` rewrites `index.html` and copies the SFX.
Running a script overwrites hand edits made in Studio to that scene, so edit either here or in the HTML, not both.
