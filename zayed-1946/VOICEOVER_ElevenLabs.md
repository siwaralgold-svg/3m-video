# الفويس أوفر — ElevenLabs

## الإعدادات (Voice Settings)

| الإعداد | القيمة |
|---|---|
| Model | **Eleven v3** (يدعم وسوم المشاعر بين الأقواس `[ ]`). بديل: Multilingual v2 (احذف الوسوم واعتمد على علامات الترقيم) |
| Voice | صوت رجالي ناضج وعميق، فصحى بلكنة خليجية خفيفة، أسلوب راوٍ وثائقي (Narrator / Documentary) |
| Stability | 45–50% (في v3 اختر **Natural**) |
| Similarity | 75–80% |
| Style Exaggeration | 25–35% |
| Speaker Boost | On |
| Speed | 1.0 (ارفعها إلى 1.05 فقط إن تجاوز مقطع زمنه) |
| Output | MP3 44.1 kHz، صدّره باسم `assets/voiceover.mp3` |

**ملاحظات النطق:** الأرقام مكتوبة بالحروف حتى تُنطق صحيحة. التشكيل موضوع على الكلمات التي يخطئ فيها النطق الآلي عادةً. الثلاث نقاط `…` تعطي وقفة قصيرة، والفاصلة تعطي نَفَساً أقصر.

## النسخة A — مضبوطة على الفيديو (33 ثانية) ✅ الموصى بها

انسخ كل سطر كما هو. الزمن بجانب كل مشهد هو المساحة المتاحة له في الفيديو.

**المشهد 1 — الهوك (0:00–0:06)**
```
[curious, intimate] هل تخيّلتَ يوماً أن هذه الواحةَ الخضراء… كانت أرضاً عطشى، [low] يُشترى فيها الماءُ بالمال؟
```

**المشهد 2 — القرار (0:06–0:12)**
```
[serious, measured] عامَ ألفٍ وتسعِمئةٍ وستةٍ وأربعين… قالها زايد: [firm] الماءُ حقٌّ للجميع. [warm] وبدأ بنفسه، فتنازل عن حصّته.
```

**المشهد 3 — العمل باليد (0:12–0:19)**
```
[determined] ولم يكتفِ بالقرار… حمل الفأسَ بيديه، وحفر مع الأهالي تحت شمس الصيف، [rising] ليُعيد الحياةَ لشرايين الواحة.
```

**المشهد 4 — الازدهار (0:19–0:26)**
```
[hopeful, building] تدفّق الماءُ مجاناً، فازدهرت العين… [proud] ومع النفط، فاض الكرمُ مدارسَ ومستشفياتٍ وبيوتاً للجميع.
```

**المشهد 5 — الختام (0:26–0:33)**
```
[reverent, slow] رحل زايدُ الخير، وبقي أثرُه في كل قطرة… [proud] مسيرةٌ أكملها الشيخ خليفة، ويقودها اليوم الشيخ محمد بن زايد.
```

> نصيحة: ولّد كل مشهد في طلب منفصل، ثم ضع كل مقطع عند بداية مشهده (0، 6، 12، 19، 26). هكذا تبقى الجمل متزامنة مع الصورة حتى لو اختلف طول جملة عن أخرى.

## النسخة B — نصك الكامل كما هو (≈ 50–55 ثانية)

مدتها أطول من الفيديو الحالي. إن اخترتها أخبرني وأمدّ المشاهد على طول التسجيل.

```
[curious, intimate] هل تخيّلتَ يوماً أن تكون هذه الواحةُ الخضراء… مجردَ أرضٍ عطشى يشتري الناسُ فيها قطرةَ الماءِ بالمال؟ [serious] في عام ألفٍ وتسعِمئةٍ وستةٍ وأربعين، وقف رجلٌ واحد… ليغيّر هذا القدرَ للأبد.

[measured, respectful] الشيخ زايد بن سلطان آل نهيان… أصدر قرارَه التاريخيّ في مدينة العين: [firm] الماءُ هبةٌ من الله، وحقٌّ للجميع. [warm] وتنازل أولاً عن حصّته وحصّةِ أسرته، ليجعلَ الماءَ مجاناً لكلّ إنسان.

[determined] لم يكتفِ بالقرار، بل نزل إلى الميدان بنفسه… حمل الفأسَ والمِسحاة، واشتغل بيديه مع الأهالي تحت شمس الصيف، [rising] ليحفروا الأرض، ويعيدوا الحياةَ لشرايين الواحة.

[hopeful, building] تدفّق الماءُ مجاناً، فازدهرت العين وتحوّلت إلى جنّةٍ خضراء… [proud] ومع اكتشاف النفط، فاض هذا الكرمُ ليبنيَ المدارسَ والمستشفياتِ والبيوت، للمواطنين والوافدين والزائرين، بلا استثناء.

[reverent, slow] رحل زايدُ الخير، وبقي أثرُه النابضُ في كلّ قطرةِ ماء، وكلّ صرحٍ شامخ… [proud] مسيرةُ عطاءٍ أكملها الشيخ خليفة، ويقودها اليوم نحو المستقبل الشيخ محمد بن زايد. [soft, final] هكذا تُبنى الأوطان… عندما يكون القائدُ هو أولَ من يُعطي.
```

## إضافة الصوت إلى الفيديو

1. احفظ الملف في `zayed-1946/assets/voiceover.mp3`.
2. في `index.html` أضف هذا السطر مكان التعليق `<!-- Voiceover ... -->`:
   ```html
   <audio id="voiceover" class="clip" src="assets/voiceover.mp3" data-start="0" data-track-index="10" data-volume="1"></audio>
   ```
3. المؤثرات الصوتية مضبوطة على 0.30–0.45 لتبقى تحت الصوت.
