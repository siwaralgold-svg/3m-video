# البيت اللي صار مستشفى — مشروع الأنيميشن

فيلم أنيميشن درامي (1920×1080، 24 إطار/ث، H.264 + AAC، 150 ث) عن سالم وأبيه في العين سنة 1960، مستوحى من تأسيس مستشفى الواحة (مستشفى كند اليوم). سالم وعائلته شخصيات متخيّلة.

- الفيديو: `renders/house-hospital.mp4` (H.264 CRF 20). نسخة الجودة الأعلى (162 MB) تُعاد بأمر الـ render أدناه.
- جدول التوقيت مربوطًا بالصوت: `TIMING.md`

## بنية المشروع
| المسار | المحتوى |
|---|---|
| `index.html` | الجذر: يركّب 17 مشهدًا من `compositions/` + الصوت + المؤثرات |
| `compositions/sc01…sc17.html` | مشهد لكل ملف؛ مواضع الشخصيات وحركاتها مفاتيح زمنية مقروءة (`T([[زمن, قيمة], …])`) و`at(…)` تحوّل زمن الصوت إلى زمن المشهد |
| `assets/rig.js` | نظام الدمى المقطّعة: رأس على محور الرقبة، ذراع بمفصلين (كتف/كوع) ويد من الرسم الأصلي، ساقان بـ IK وقدمان ثابتتان على الأرض أثناء الارتكاز (لا انزلاق)، تمايل ذيل الثوب، تنفّس، ظل تماس |
| `assets/rig/<شخصية>/` | أجزاء كل دمية: `body.png` (الجسم بعد إزالة اليد وترميم ما تحتها)، `head.png`، `hand0.png` |
| `assets/rigs.js` | المفاصل ومحاور الدوران وألوان الأكمام لكل دمية |
| `assets/src/cutouts/` | كل الشخصيات والزوايا والأدوات مقصوصة بشفافية (×4) |
| `assets/chars/`, `assets/props/`, `assets/bg/` | الأهل والأدوات والخلفيات المستخدمة |
| `tools/build_scenes.py` | يولّد ملفات المشاهد و`index.html` (عدّل هنا ثم شغّل `python3 tools/build_scenes.py`) |
| `tools/asset-pipeline/` | سكربتات القص وإزالة الخلفيات والتكبير وبناء الأجزاء |
| `tools/voice_transcript.json` | تفريغ الصوت على مستوى الكلمة |

## التعديل والمعاينة
```bash
npx hyperframes preview          # معاينة وتعديل
npm run check                    # الفحص
npx hyperframes render --fps 24 -q delivery -o renders/house-hospital.mp4
```

## كيف جُهّزت الأصول
1. فُصلت كل شخصية وزاوية من اللوحات: أُزيلت الخلفية الفاتحة والعناوين في لوحتي العائلة والطبيبين بالتعبئة من الأطراف، وقُصّت حواف التوهج في لوحات أهل الحي والأدوات بعتبة شفافية.
2. كُبّرت ×4 (Real-ESRGAN anime) للملابس والأدوات. الوجوه والأيدي كُبّرت بإعادة عيّنة عادية ثم سُطّحت، لأن المكبّر أضاف ملامح وهمية للوجه الجانبي؛ الوجوه كلها سادة.
3. لكل دمية: فُصلت اليد من الرسم وأُعيد ملء ما تحتها، وفُصل الرأس فوق الرقبة، وأُزيلت القدمان في زاوية الجانب لتحلّ محلها قدمان متحركتان بلون الصندل نفسه.

## حدود معروفة
- الأكمام المتحركة مرسومة متجهيًا بلون الثوب المأخوذ من الرسم وخط أغمق؛ تبدو أبسط قليلًا من الرسم الأصلي عند الحركة الواسعة.
- الدوران بين الزوايا (جانب ↔ ثلاثة أرباع) فوري عند القطع أو التوقف، بلا رسوم وسيطة.
- أهل الحي صور كاملة بتمايل وتنفّس وميل خفيف، لا يمشون (لا توجد لهم زوايا جانبية للمشي دون انزلاق).
- الفحص بالسماعة ومسك اليد يجريان والأب واقف بجانب سرير الفحص؛ وضعية الجلوس من الزاوية الأمامية لم تكن مقنعة بالأصول المسطّحة.
- لا مؤثرات بيئية (طيور/ريح): مكتبة المؤثرات في الريبو ليس فيها أصوات بيئية، وتنزيل تسجيل CC0 من Openverse/freesound رُفض في هذه البيئة. المؤثرات الموجودة قليلة ومرتبطة بأفعال على الشاشة.
