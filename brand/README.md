# T3M brand

Use these in every T3M video.

## Logo

| File | Use on |
| --- | --- |
| `t3m-logo.svg` | Light backgrounds (navy + gold) |
| `t3m-logo-light.svg` | Dark backgrounds, e.g. navy video backgrounds (light + gold) |

Both are vector SVGs (884 × 1044 ratio). Don't recolour, stretch or redraw the logo.

## Colours

| Name | Hex | Role |
| --- | --- | --- |
| Navy | `#1C385A` | Main brand colour (the T, the 3 and the centre sword) |
| Gold | `#CEA532` | Accent (the M and the side swords): highlights, underlines, key numbers |
| Light | `#F4F6F9` | Text and logo colour on dark backgrounds; light backgrounds |
| Deep navy | `#13294B` | Dark background colour used in the T3M company profile |
